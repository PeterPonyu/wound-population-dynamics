# Conditional flow matching audit: current analysis reproduction

This is the version 0.5.0 current-analysis closure. Software DOI 10.5281/zenodo.23308074
was reserved at archive assembly; it identifies this software/reproduction release,
not a manuscript or preprint. Publication is handled separately.
Native producing bytes and paths are preserved in this directory; run commands
from this directory. REPRODUCTION_CLOSURE.json binds every included native input,
program, checkpoint, protocol and result. Historical paths in unmodified reports
describe the producing environment; do not resume relocated historical runs.

```sh
python3 verify_revision.py --smoke
python3 verify_revision.py --saved-checks --output-dir tmp/reproduction-check-01
```

Use a new output directory for every verification. The first command checks all
hashes, parses Python sources, imports the model/analysis helpers and checks safe
CLI help entry points. The second additionally recomputes available saved-input
results. Verification does not fit neural models, create a release, or download
source data. Existing optional trainers must be run only after creating a fresh
run contract and fresh output path; original approval/resume receipts are
historical provenance, not authorization to reuse a relocated run.

The native population tree contains all five representation coordinate caches,
354 original follow-up fields and their complete predictions, nine selected outer
fields, matched-draw evaluation tables, nested-selection scores, target-informed
alpha diagnostics, OOD/shrinkage summaries and the training-only empirical decoder
expression summaries. The original 107-job local harness is included with its
predictions, evaluation contracts and replay states. The exact standardized
GSE241132 counts, barcodes and frozen encoder means are included, along with the
frozen model, source panel and human metadata. The GSE186527 public processed
counts, HTO dictionary, admission matrices and saved replay fields retain all
failed admission arms and the lineage-positive PBS task. There are three human
donors; seeds, representation changes and cell draws do not add donors.

The verification wrapper recomputes the 2,700 deterministic-control rows and checks
the saved coordinate/field grid without requesting CUDA replay. A separate
full saved-field audit rederives the 31 coordinate matrices and reconstructs the
matched summaries, with fresh outputs. Original-CUDA replay evidence is included
as historical evidence. Strict saved-field CPU replay previously failed and is
not certified by these import, checksum or deterministic-control checks. Historical
original training-time input hashes are unavailable; replay and retrospective
bindings do not prove exact retraining. The complete alpha grid is not replayed.

The earlier 48-flow/12-baseline finite-budget diagnostic is preserved with all
60 jobs, saved predictions, scalar records, protocol and source verification.
Its fields were not retained by the producing run, so those 48 fields cannot be
reloaded from this archive. The scalar summaries can be reconstructed from the
included authenticated results; a new training run would be a separate exercise.

The full saved-coordinate audit command is
`python3 scripts/audit_followup_integration.py --output-dir tmp/full-saved-audit-01 --nested-dir output/followup-integration-20261011-r1/p2/nested-refits`.
It preserves the original tolerances. The successful portable check used the
unchanged default 24-thread OpenBLAS runtime; one- and two-thread checks exceeded
the PCA tolerance and are retained in verification/. This qualification concerns
PCA recomputation and does not certify strict saved-field CPU reintegration.


The existing runtime is recorded in environment.observed.json and
requirements.observed.txt; those files observe installed packages and perform no
installation. Producing package/device information remains in native protocols,
receipts and reports. The software license does not relicense source data, model
weights, numerical results or manuscript material; see the enclosing NOTICE.

Source-data acquisition and access instructions remain in the enclosing
REPRODUCIBILITY.md, scripts/fetch_*.sh and the native expansion/registry/datasets.json.
GEO processed count matrices and array signals retain source-study terms. Included
files named RAW.tar contain public processed count matrices, not human sequencing
reads. Controlled human sequencing reads were not used or redistributed; the
source registry records EGA-controlled raw reads for relevant public processed
cohorts. Access to such reads must follow the source study's stated EGA procedure.
No controlled-access data are needed for the saved-input verification commands.

The frozen representation and discovery source data retain their shared provenance.
A separately runnable copy does not make them statistically independent or supply
new biological validation. Every native_input_bindings entry records either an
exact included match or a specific provenance gap; a missing historical binding
is not silently replaced by a current digest.
